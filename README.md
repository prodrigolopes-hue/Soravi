# Soravi

Plataforma brasileira para conectar pessoas a profissionais e soluções de serviços.

## Status
MVP em desenvolvimento.

## Estrutura
- `apps/web`: Next.js
- `apps/api`: NestJS
- `docs`: documentação
- `infra`: infraestrutura local

## Executar
```bash
npm install
docker compose up -d
npm run dev
```
