# 00 - Contexto Geral da Soravi

## Resumo

A Soravi é uma startup brasileira criada para conectar pessoas a
profissionais e soluções de serviços.

Pergunta central: \> **Como podemos ajudar você hoje?**

## Missão

Conectar pessoas a profissionais de forma simples, rápida e segura.

## Visão

Ser a principal plataforma brasileira para contratação de serviços
locais.

## Público

-   Cliente
-   Profissional
-   Administrador

## MVP

-   Cadastro
-   Login
-   Perfil de Cliente
-   Perfil Profissional
-   Solicitações de Serviço
-   Propostas
-   Chat
-   Avaliações
-   Favoritos
-   Notificações
-   Painel Administrativo

## Stack

Frontend: - Next.js - React - TypeScript - Tailwind CSS - shadcn/ui

Backend: - NestJS - Prisma - PostgreSQL - Redis

## Metodologia

Desenvolvimento commit por commit.
