# 05 - Design System

# Objetivo

Definir os padrões visuais e de experiência da Soravi para garantir
consistência em toda a plataforma.

------------------------------------------------------------------------

# Identidade

A Soravi deve transmitir:

-   confiança;
-   simplicidade;
-   modernidade;
-   proximidade.

------------------------------------------------------------------------

# Paleta de Cores

## Primária

-   Azul (#2563EB)

Representa confiança e tecnologia.

## Secundária

-   Verde (#22C55E)

Representa sucesso e confirmação.

## Apoio

-   Branco
-   Cinza claro
-   Cinza escuro

------------------------------------------------------------------------

# Tipografia

Fonte principal:

-   Inter

Hierarquia:

-   H1
-   H2
-   H3
-   Texto
-   Legenda

------------------------------------------------------------------------

# Espaçamento

Sistema baseado em múltiplos de 4px.

Exemplos:

-   4
-   8
-   12
-   16
-   24
-   32
-   48

------------------------------------------------------------------------

# Componentes

## Botões

Tipos:

-   Primário
-   Secundário
-   Contorno
-   Texto

Estados:

-   Normal
-   Hover
-   Pressionado
-   Desabilitado

------------------------------------------------------------------------

## Campos

Todos devem possuir:

-   label;
-   placeholder;
-   mensagem de erro;
-   validação visual.

------------------------------------------------------------------------

## Cards

Utilizados para:

-   profissionais;
-   solicitações;
-   propostas;
-   notificações.

------------------------------------------------------------------------

## Ícones

Biblioteca padrão:

-   Lucide React

------------------------------------------------------------------------

# Responsividade

Prioridade:

1.  Mobile
2.  Tablet
3.  Desktop

Toda tela deve funcionar corretamente em dispositivos móveis.

------------------------------------------------------------------------

# UX

Princípios:

-   poucos cliques;
-   linguagem simples;
-   feedback imediato;
-   acessibilidade;
-   carregamento rápido.

------------------------------------------------------------------------

# Componentes Reutilizáveis

-   Navbar
-   Footer
-   Card de Profissional
-   Card de Solicitação
-   Card de Proposta
-   Modal
-   Toast
-   Avatar
-   Badge
-   Loader
-   Paginação

------------------------------------------------------------------------

# Objetivo Final

Criar uma interface limpa, intuitiva e escalável, reforçando a
identidade da Soravi em todos os pontos de contato com o usuário.
