# 01 - Visão do Produto

# Propósito

A Soravi existe para conectar pessoas que precisam resolver problemas a
profissionais capazes de solucioná-los.

Mais do que anunciar serviços, a plataforma deve facilitar toda a
jornada do usuário.

------------------------------------------------------------------------

# Problema

Hoje, encontrar um profissional confiável costuma exigir pesquisas em
diversos canais, indicações e troca de mensagens.

Isso gera demora, insegurança e dificuldade para comparar opções.

------------------------------------------------------------------------

# Solução

A Soravi permite que o cliente descreva sua necessidade e receba
propostas de profissionais qualificados.

Fluxo principal:

1.  Cliente descreve o problema.
2.  A Soravi identifica a categoria.
3.  Profissionais recebem a oportunidade.
4.  Enviam propostas.
5.  Cliente compara.
6.  Escolhe.
7.  Conversa pelo chat.
8.  Avalia o serviço.

------------------------------------------------------------------------

# Proposta de Valor

Para clientes:

-   rapidez;
-   confiança;
-   comparação de propostas;
-   facilidade de contratação.

Para profissionais:

-   novas oportunidades;
-   visibilidade;
-   reputação;
-   relacionamento com clientes.

------------------------------------------------------------------------

# Diferenciais

-   Linguagem simples.
-   Busca orientada ao problema do usuário.
-   Processo completo de contratação.
-   Interface moderna e mobile-first.

------------------------------------------------------------------------

# Princípios do Produto

-   Simplicidade.
-   Transparência.
-   Segurança.
-   Agilidade.
-   Escalabilidade.

------------------------------------------------------------------------

# Objetivo do MVP

Validar a conexão entre clientes e profissionais com o menor número
possível de etapas, mantendo excelente experiência de uso.

------------------------------------------------------------------------

# Métricas de Sucesso

-   Usuários cadastrados.
-   Solicitações criadas.
-   Propostas enviadas.
-   Taxa de contratação.
-   Avaliações concluídas.
-   Retenção de usuários.
